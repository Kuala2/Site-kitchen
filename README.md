# СЛОЙ 52

Полностью локальный демонстрационный сайт вымышленного производителя кухонь на заказ. Построен на Next.js App Router, React и TypeScript. Конфигуратор хранит только параметры кухни в URL и localStorage. Форма ничего не отправляет.

## Запуск

```bash
npm install
npm run dev
```

Проверки: `npm run lint`, `npm test`, `npm run test:e2e`, `npm run build`, `npm start`.

## Где менять данные

- `data/site.ts` - бренд, регион, домен и единый `demoMode`.
- `data/projects.ts` - концепты и тексты.
- `data/materials.ts` - материалы.
- `data/pricing.ts` - демонстрационная ценовая матрица и диапазоны размеров.
- `lib/configurator.ts` - чистый расчёт, валидация и сериализация.

## Перед публикацией реального сайта

Замените название, домен, контакты, регион, проекты, фотографии, цены, юридические документы, способ отправки формы, metadata и содержимое страниц. Добавьте проверенные условия производства, сроки и гарантии. Переключите `demoMode` в `false`, настройте аналитику с согласием пользователя и добавьте LocalBusiness JSON-LD только с реальными данными. Проверьте canonical, robots и sitemap на рабочем домене.

Для формы потребуется согласованный обработчик или CRM, серверная валидация, защита от спама, политика обработки данных и согласие. Персональные данные нельзя переносить в URL или localStorage.
